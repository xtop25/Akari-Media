# Akari Media

Десктопный медиаплеер на Tauri 2, React и TypeScript с каталогом аниме Shikimori. Этот архив содержит **исходный код**, а не готовый установщик Windows.

## Что работает

- Главная, каталог с поиском и фильтрами, расписание Shikimori. Если там нет постера, используется AniList по точному ID; если постер недоступен в обоих сервисах, показывается заглушка.
- Поиск доступных серий AniLibria v1 по точному Shikimori ID; выбор серии и качества. Для отсутствующих или недоступных релизов можно открыть свою прямую HTTP(S)-ссылку на MP4/M3U8.
- Плеер HLS и обычного видео, сохранение позиции, продолжение из истории, избранное и настройки. Русский и английский интерфейсы; названия и описания поступают из Shikimori и могут оставаться на языке источника. Данные хранятся локально на устройстве. Собственная ссылка на видео не сохраняется — после возвращения её нужно ввести снова.
- Закрепление окна поверх остальных в Tauri и «картинка в картинке», если WebView/браузер поддерживает этот режим.

Shikimori предоставляет только метаданные, а не видео. Не все тайтлы есть в AniLibria; доступ и реклама зависят от сервиса, региона и условий правообладателей. Не используется обход блокировок, DRM и рекламы. Озвучки сторонних сервисов и каталог фильмов/сериалов не подключены. Веб-браузеру требуется CORS для сторонних видеопотоков. Встроенный плеер не воспроизводит страницы и iframe как прямые ссылки.

## Быстрый запуск в браузере

Нужен Node.js 20 или новее и интернет:

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:1420). Это удобно для проверки, но возможности управления десктопным окном в браузере недоступны.

## Windows: запуск и сборка

1. Установите Node.js 20+, Rust (rustup), Microsoft C++ Build Tools и WebView2, как описано в [инструкции Tauri](https://v2.tauri.app/start/prerequisites/).
2. В папке проекта выполните:

```bash
npm ci
npm run tauri dev
```

Для создания установщика:

```bash
npm run tauri build -- --bundles nsis
```

Готовый `.exe` ищите в `src-tauri/target/release/bundle/nsis/`. Рабочий процесс `.github/workflows/windows-build.yml` также предназначен для сборки установщика в GitHub Actions: загрузите файлы в репозиторий, запустите **Actions → Windows installer → Run workflow** и скачайте артефакт. Сборка Tauri на Windows и этот workflow в текущей среде не проверялись.

## Проверки

`npm run build` выполняет TypeScript-проверку и сборку фронтенда. Для браузерного smoke-теста: установите Chromium командой `npx playwright install chromium`, запустите `npm run dev` в отдельном терминале и выполните `node tests/smoke.cjs`. Дополнительная проверка перевода и резервных постеров — `node tests/language-posters.cjs`. Тесты подменяют ответы API и использует включённый короткий тестовый видеофайл; реальные сервисы и геодоступность он не проверяет. Чтобы использовать системный Chromium, задайте `CHROMIUM_PATH`.

Реальный Shikimori и AniLibria v1, а также воспроизведение одного HLS-потока в Chromium проверены в среде разработки. Поведение сторонних сервисов может измениться.
