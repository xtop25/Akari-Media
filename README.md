# Akari Media

Десктопный медиаплеер на Tauri 2, React и TypeScript с каталогом аниме Shikimori. Версия 0.4.0 — подготовительная сборка; условия публичного распространения сторонних источников ещё не согласованы.

## Что работает

- Главная со случайным выбором аниме, каталог с поиском и фильтрами, расписание Shikimori. Если там нет постера, используется AniList по точному ID; если постер недоступен в обоих сервисах, показывается заглушка.
- Сезоны и продолжения показаны над плеером; при недоступности Shikimori приложение пытается получить связи prequel/sequel из AniList. При желании можно открыть свою прямую HTTP(S)-ссылку на MP4/M3U8.
- Экспериментальный YummyAnime: альтернативный русский источник для **личного использования**. Пользователям не нужно вводить ключ: в тестовую версию включён публичный токен приложения (не личный токен и не пароль). Поиск сверяет точный Shikimori ID; поддерживаются iframe Aksor и CVH, экспериментально добавлены Kodik и Alloha; выбор доступной озвучки и серии, включая переход по номеру. Выбор источника, серии и озвучки запоминается на устройстве, если включена соответствующая настройка; позиция видео стороннего плеера не сохраняется. Есть кнопки предыдущей и следующей серии. При ошибке интерфейс показывает этап (поиск или список серий) и безопасную диагностику без ключа. Каталог, доступность и ограничения по странам определяет источник.
- Экспериментальный встроенный сторонний плеер Cinextream: японский звук/субтитры и выбор английского дубляжа. Список номеров берётся из Shikimori, а не из поставщика видео; наличие каждой серии и озвучки не гарантировано. Встроенный плеер открывается только после выбора пользователем.
- Ссылки на внешние стриминговые сервисы по ID AniList. Ссылки открываются в браузере, а не во встроенном плеере; каталог и доступность зависят от сервиса и региона.
- Плеер HLS и обычного видео, сохранение позиции, продолжение из истории, избранное и настройки. Русский и английский интерфейсы: для новых пользователей по умолчанию выбран английский, ранее сохранённый язык не меняется; названия и описания поступают из Shikimori и могут оставаться на языке источника. Данные хранятся локально на устройстве. Собственная ссылка на видео не сохраняется — после возвращения её нужно ввести снова.
- Личная библиотека: статусы просмотра, оценки 1–10 и заметки, поиск и фильтрация. Данные хранятся локально. Экспорт JSON содержит только библиотеку и личные заметки, не избранное и не прогресс; импорт после подтверждения полностью заменяет библиотеку.
- Недавние выбранные серии помогают вернуться к аниме; это история выбора, а не подтверждение просмотра. Предпочитаемую русскую озвучку можно сохранить на устройстве: сохранённый выбор конкретного аниме имеет приоритет, иначе используется предпочтение при точном совпадении названия, затем стандартный вариант.
- Закрепление окна поверх остальных в Tauri и «картинка в картинке», если WebView/браузер поддерживает этот режим.

Shikimori предоставляет только метаданные, а не видео. Cinextream — независимый источник с непроверенными правами на видео, и его видео, реклама и доступность зависят от сервиса и региона. Перед публичным распространением проверьте права и условия использования источников. Не используется обход блокировок, DRM и рекламы. Права на видео сторонних плееров не проверены; поддержка Yummy предложила направить запрос о сотрудничестве на promotion@yummyani.me; разрешение не получено. Документация API YummyAnime ограничивает использование личными целями и предлагает связаться с сервисом по коммерческим вопросам; до публичного распространения отдельно выясните условия использования и права. Каталог фильмов/сериалов не подключён. Веб-браузеру требуется CORS для сторонних прямых видеопотоков; сторонний плеер загружается отдельно в ограниченном iframe.

## Быстрый запуск в браузере

Нужен Node.js 20 или новее и интернет:

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://localhost:1420). Это удобно для проверки, но возможности управления десктопным окном в браузере недоступны.

## Windows: запуск и сборка

1. Установите Node.js 20+, Rust (rustup), Microsoft C++ Build Tools и WebView2, как описано в [инструкции Tauri](https://v2.tauri.app/start/prerequisites/).
2. В папке проекта выполните:

```bash
npm ci
npm run tauri dev
```

Тестовая сборка включает публичный токен приложения в клиентском коде; его могут увидеть пользователи, поэтому он не является секретом. Приватный токен и пароль никогда не добавляйте. Для публичного распространения требуется согласование с сервисом.

Для создания установщика:

```bash
npm run tauri build -- --bundles nsis
```

Готовый `.exe` ищите в `src-tauri/target/release/bundle/nsis/`. Рабочий процесс `.github/workflows/windows-build.yml` также предназначен для сборки установщика в GitHub Actions: загрузите файлы в репозиторий, запустите **Actions → Windows installer → Run workflow** и скачайте артефакт. Этот сценарий запускает сборку на Windows в GitHub Actions; успешную сборку и работу установленного приложения необходимо проверить для каждой новой версии.

## Проверки

`npm run build` выполняет TypeScript-проверку и сборку фронтенда. Для браузерного smoke-теста: установите Chromium командой `npx playwright install chromium`, запустите `npm run dev` в отдельном терминале и выполните `node tests/smoke.cjs`. Дополнительная проверка перевода и резервных постеров — `node tests/language-posters.cjs`, `node tests/seasons.cjs`, `node tests/seasons-fallback.cjs`, `node tests/season-collapse.cjs`, `node tests/streaming.cjs`, `node tests/catalog-pagination.cjs`, `node tests/cinextream.cjs` и `node tests/default-language.cjs` , `node tests/yummy.cjs` и `node tests/yummy-errors.cjs`, `node tests/yummy-diagnostics.cjs` и `node tests/surprise.cjs`, а также `node tests/library.cjs` и `node tests/preferred-recent.cjs`. Тесты подменяют ответы API и используют включённый короткий тестовый видеофайл; реальные сервисы и геодоступность он не проверяет. Чтобы использовать системный Chromium, задайте `CHROMIUM_PATH`.

Реальный Shikimori и воспроизведение одного HLS-потока в Chromium проверены в среде разработки. Поведение сторонних сервисов может измениться.

## Статус проверки нового источника

Cinextream — экспериментальная интеграция: в изолированном iframe Chromium воспроизводились тестовые серии «One Piece» (1, 1000 и 1100), «Attack on Titan» и «Kuroko’s Basketball»; аудиодорожки и другие серии отдельно не проверены. В среде локального приложения запросы к сервису блокировались, поэтому работу в Windows WebView2 и конкретном регионе необходимо проверить. Реестр номеров серий не подтверждает доступность видео.


Проверка YummyAnime: в отдельном Chromium с ограниченным iframe после рекламы воспроизводились первая серия «Баскетбола Куроко» и серии 1, 1000 и 1100 «One Piece» (данные о названиях озвучек предоставлены каталогом; звук и другие серии отдельно не проверялись). Код интеграции и выбор серий проверены на подменённых ответах API; авторизованные запросы каталога и видео проверены с публичным токеном. В локальном Chromium серия 1000 One Piece и первые серии «Магии вернувшегося», «Баскетбола Куроко» и «Атаки титанов» запускались из приложения; звук и Windows WebView2 пока не проверены. При проверке Kodik сообщал о недоступности видео, а Alloha — о региональном ограничении; их воспроизведение не подтверждено. Доступность зависит от страны и сервиса.
